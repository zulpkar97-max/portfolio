# Security Policy

## Scope

This policy covers security issues affecting the current production portfolio site or the code on the current `master` branch of this repository.

Issues in third-party platforms, services, packages, or libraries are governed by their respective maintainers. Reports are still welcome when a third-party issue creates a demonstrable security impact on this portfolio.

## Reporting a vulnerability

Please do not disclose potential security vulnerabilities through a public GitHub issue.

Report them privately to [zulpkar97@gmail.com](mailto:zulpkar97@gmail.com). Include, where possible:

- the affected page, route, or repository file;
- clear and minimal reproduction steps;
- the potential security impact; and
- relevant screenshots or a minimal proof of concept that can be shared safely.

Do not include passwords, API keys, personal data, destructive payloads, or unnecessary executable attachments.

This is a static portfolio repository. No guaranteed response time, vulnerability bounty, or enterprise security-support commitment is offered.
